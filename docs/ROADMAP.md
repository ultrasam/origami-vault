# Roadmap

## Purpose

This roadmap outlines the planned evolution of Origami Vault from a concept and knowledge repository into a comprehensive platform for preserving, sharing, learning, and advancing origami knowledge.

The roadmap is intended to guide development priorities while remaining flexible enough to evolve as the project, community, and technology landscape change.

---

# Phase 0 - Research & Foundations

## Goal

Establish a solid understanding of the origami software ecosystem before major development begins.

### Milestones

#### Repository & Documentation

- Establish project structure
- Create README.md
- Create VISION.md
- Create FOUNDER.md
- Create ROADMAP.md
- Create ARCHITECTURE.md
- Create REQUIREMENTS.md
- Create RESEARCH.md

#### Ecosystem Research

- Research existing origami software
- Research ORIPA
- Research Ori Studio
- Research Origami Simulator
- Research FoldMation
- Research existing origami databases

#### Standards Research

- Study the FOLD format
- Identify strengths and limitations of FOLD
- Determine whether FOLD can serve as a primary interchange format
- Research additional origami file formats
- Document interoperability opportunities

#### Architecture Research

- Evaluate Ruby on Rails for web platform
- Evaluate Godot + C# for desktop application
- Evaluate PostgreSQL storage requirements
- Define initial architectural principles

### Exit Criteria

- Technical foundations documented
- Existing standards understood
- Initial architecture defined
- MVP scope identified

# Version 0.1 - Foundation

## Goal

Create the first usable version of Origami Vault focused on preserving and sharing origami knowledge.

This phase prioritizes content, creators, discoverability, and preservation.

## Features

### User Accounts

- Registration and authentication
- User profiles
- Basic account management

### Origami Models

- Create model entries
- Edit model information
- Upload model images
- Categorize models

### Metadata

- Model name
- Designer / Creator
- Difficulty level
- Tags
- Estimated folding time
- Recommended paper size
- Recommended paper type

### Instructions

- Step-by-step instructions
- Images for each step
- Notes and tips

### Search & Discovery

- Search by name
- Search by creator
- Search by category
- Search by tags

### Collections

- Favorite models
- Personal collections

### Standards Integration

- Import metadata from supported formats
- Store references to FOLD files when applicable
- Preserve interoperability opportunities for future versions

### Not Included

- 3D simulation
- Fold animation
- Public API
- Advanced creator tools
- Geometry generation

# Guiding Philosophy

The purpose of the roadmap is not to build every possible feature.

The purpose is to advance the mission of Origami Vault:

To preserve, share, celebrate, and advance the knowledge and beauty of origami.

When making development decisions, priority should always be given to features that increase the accessibility, preservation, and discoverability of origami knowledge.

Roadmaps evolve.

The mission does not.
