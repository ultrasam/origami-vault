# Contributing to Origami Vault

Thank you for your interest in contributing. We welcome contributions of all kinds — bug reports, feature requests, documentation improvements, tutorials, examples, and code.

How to contribute

1. Search existing issues and the roadmap before opening a new issue.
2. Open an issue describing the bug or feature idea.
3. If you want to submit code, open a pull request targeting the `main` branch.

Pull request guidelines

- Fork the repository (if you don't have push access).
- Create a feature branch named `feature/short-description` or `fix/short-description`.
- Keep commits small and focused; write clear commit messages.
- Include tests where applicable and update documentation when adding features.
- Link the PR to any relevant issues.

Code style

- Follow existing code style in each subproject. Add a linter or formatter configuration if you introduce a new language.
- For C# projects, prefer the .NET conventions and use dotnet-format or an editorconfig.

Communication

- Be respectful and constructive.
- If your change is large, open an issue first to discuss the approach.

Security

If you discover a security vulnerability, please do not open a public issue. Contact the maintainers privately. Add a SECURITY.md later with responsible disclosure details.
