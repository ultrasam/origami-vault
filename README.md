# Origami Vault

A universal platform for discovering, sharing, preserving, and learning origami.

Created by Sócrates Medina.

## About

Origami Vault is a project to create a central home for origami models, folding instructions, creators, and digital knowledge about the art of paper folding.

## Getting started

This repository is organized into multiple top-level folders (backend, frontend, shared, prototypes, docs, assets). Each area includes a README with next steps for that component.
